# Malek for Website — معرض أعمال وباقات

موقع شخصي عربي (RTL) لمقدم خدمة تصميم وتطوير المتاجر الإلكترونية، مع معرض
للمشاريع الحقيقية، وباقات أسعار، وربط مباشر بالواتساب.

الملف الجاهز للنشر هو **`index.html`** — ملف واحد مستقل تمامًا: الخطوط
(El Messiri / Cairo / Cormorant) وصور المتاجر الحقيقية وكل الـ CSS والـ JS
مضمّنين داخله كـ data URIs، فلذلك يعمل أوفلاين وداخل أي معاينة sandbox تمنع
الطلبات الخارجية. لا CDN ولا npm ولا خطوة بناء مطلوبة للنشر.

```
index.html              ← النسخة النهائية (مستقلة، ~835 KB)
src/index.tpl.html      ← قالب الصفحة (المصدر الحقيقي — فيه placeholders اللوجو)
src/index.html          ← مولّد من القالب، متعدّلوش بإيدك
render.py               ← يحقن مسارات اللوجو + الفافيكون + روابط واتساب
src/styles.css          ← التصميم كامل (tokens + components + breakpoints)
src/app.js              ← شاشة التحميل، الريفييل، العدادات، رسائل الواتساب
brand-spec.md           ← هوية البراند: اللوجو، الألوان، الخطوط، الصور، الصوت
assets/brand/*.svg      ← اللوجو (light/dark/currentColor + lockups)
assets/live/*.webp      ← صور المنتجات المسحوبة من المتاجر الشغّالة
assets/projects/*.webp  ← صور إضافية من مشروعي عوام الدلنجات وCLOTHINA
fonts/*.woff2           ← El Messiri + Cairo (عربي ولاتيني) + Cormorant
build.py                ← يعيد بناء index.html من ملفات src/
vercel.json             ← إعدادات نشر على Vercel (clean URLs + headers)
```

بعد أي تعديل في `src/`:

```bash
python3 build.py
```

`build.py` بينادي `render.py` الأول، اللي بيعمل خطوتين على القالب:

1. بيحقن مسارات اللوجو المترسّمة (`/tmp/trace/paths.json`) والفافيكون.
2. بيبني روابط واتساب مسبقًا **لكل عنصر فيه `data-wa`** — الرسالة بتتكتب مرة
   واحدة في `render.py` وبتتطابق مع نسخة `app.js`.

وفيه تحقق (`verify`) بيرفض البناء لو أي `<a>` فيه `data-wa` طلعت لوِتساب
من غير `data-wa`، أو العكس — ده كان بق يحصل قبل كده وبيسبب إن لينكات التنقّل
تتحوّل لواتساب.

```bash
python3 render.py   # الخطوة الأولى لوحدها (لو عايز تشوف الـ HTML المولّد)
```

## ربط الواتساب

الرقم: **+20 105 524 7802** (`201055247802`) — في مكان واحد داخل `src/app.js`:

```js
var PHONE = '201055247802';
```

كل زر فيه `data-wa="..."` بياخد رسالة جاهزة مختلفة:

| data-wa | الرسالة |
| --- | --- |
| `plan-1` / `plan-2` / `plan-3` | اسم الباقة + السعر + كل تفاصيلها سطر سطر |
| `advice` | طلب ترشيح باقة |
| `general` | رسالة عامة للتواصل |
| نموذج التواصل | الاسم + الباقة + تفاصيل المشروع |

الروابط نفسها **مكتوبة ومُرمّزة مسبقًا في HTML**، فلو الجافاسكريبت متعطّل
الزر شغّال برضه. لما حد يدوس على أي باقة، بيفتح واتساب على الرقم برسالة
جاهزة فيها الباقة اللي داس عليها وتفاصيلها.

## التصميم

| Token | القيمة | الاستخدام |
| --- | --- | --- |
| `--ink` | `#0D0D0D` | خلفية الموقع (النسخة الداكنة) |
| `--ink-soft` / `--ink-panel` | `#171717` / `#1C1C1C` | أسطح مرتفعة وكروت |
| `--paper` | `#F7F5F1` | النصوص الأساسية والأسطح الفاتحة (النسخة الفاتحة) |
| `--paper-2` / `--paper-3` | `#EDEAE3` / `#DCD8CF` | أسطح فاتحة متبادلة وحدود |
| `--stone` | `#8C8880` | نص ثانوي على الداكن (5.5:1) |
| `--stone-2` | `#6B6862` | نص ثانوي على الفاتح (5.1:1) |
| `--display` | El Messiri | العناوين العربية |
| `--sans` | Cairo | النصوص والأزرار |
| `--serif` | Cormorant | الأرقام واللاتيني (MALEK / MW / 2026) |

**مونوكروم بالكامل** — مفيش أي لون (hue) في الموقع، الألوان كلها مشتقة من
اللوجو الأسود/الأبيض. الأسعار والأرقام في العناوين العربية بتتكتب بخط
Cormorant السيرِف عن طريق `.num` لأن مجموعات El Messiri/Cairo العربية مفيهاش
أرقام لاتينية.

الشبكة مبنية بـ `clamp()` وبريك بوينتس عند **1080 / 980 / 700 / 460px**.
الموقع كامل RTL عبر `dir="rtl"` وخصائص منطقية (`inset-inline`, `padding-inline`).

### اللوجو
مارك **MW** مأخوذ من صورة اللوجو الأصلية — اتعملها crop وتكبير ٤× وthreshold
وتتبع آلي (marching squares + Douglas–Peucker + Chaikin) فطلع SVG بأربع
مسارات مغلقة، مش خط جاهز ولا صورة. المارك مفيهوش أي لون ثابت:
`fill="currentColor"`، فبياخد لون النص في أي مكان.

النسخ الموجودة:

| الملف | الاستخدام |
| --- | --- |
| `assets/brand/mw-mark.svg` | داخل الموقع (currentColor) |
| `assets/brand/mw-mark-light.svg` | جليف ورقي على بلاطة حبر — أسطح داكنة، أفاتار، سوشيال |
| `assets/brand/mw-mark-dark.svg` | جليف حبر على بلاطة ورق — أسطح فاتحة، طباعة، عروض |
| `assets/brand/mw-lockup-{light,dark}.svg` | اللوجو مع كلمة MALEK — عروض وإيميل |

نفس المارك مستخدم في: شاشة التحميل (بيتبني قطع)، الهيدر، الفوتر، الختم
الدوّار، والـ favicon.

## الحركة والأنيميشن

- **شاشة التحميل (أنيميشن اللوجو)**: المارك بيتبني من 4 قطع كل واحدة بتطير
  من ناحية مختلفة — `W` من فوق، `M` من تحت، والمثلثين من الجناب — وبيتجمعوا
  في النص، بعدها خط حبر بيقطع المارك عرضيًا وبيتلاشى، وحروف `MALEK` بتطلع
  واحد ورا التاني، وبعدها `FOR WEBSITE`. عدّاد النسبة بيقف عند 100 في نفس
  اللحظة اللي آخر حرف بيقع فيها (~1.75 ث). حماية: لو JS وقع، `setTimeout`
  في `<head>` بيشيل الستارة بعد 6 ثواني، ولو `prefers-reduced-motion` الستارة
  بتتشال فورًا.
- **دخول الهيرو**: كل سطر بيظهر بتأخير متتابع بعد فتح الستارة.
- **ظهور السكاشن**: IntersectionObserver + `translateY` + fade مع `data-delay`.
- **عدادات الأرقام** في الهيرو بتعد لحد الرقم النهائي.
- **خط سير الماركي**، ختم دوّار، أورب بخلفية متحركة، شريط تقدم الصفحة.
- **الباقات**: أرضية ورقية بتطلع من تحت (`scaleY`) عند الهوفر، وكل النصوص
  بتقلب من الورقي للحبري في نفس الوقت.
- **صور المشاريع**: أبيض وأسود، وبتدّي لونها الحقيقي عند الهوس.
- كل الحركة تحترم `prefers-reduced-motion`: بتتحول لنسخة ساكنة فورًا.

## النشر

Vercel جاهز (Static / Other، بدون Build Command، Output = الجذر):

```bash
npx vercel --prod
```

أو ارفع الريبو على GitHub واربطه بمشروع Vercel جديد؛ `index.html` هو الملف
اللي هيتقدّم تلقائيًا. ملف `vercel.json` بيضبط clean URLs وheaders للكاش
والأمان.

## إمكانية الوصول والأداء

- HTML صالح 100% حسب `html-validate` (semantic landmarks, labels, roles).
- skip link، حالات تركيز واضحة، `aria-expanded` / `aria-live` على الحالة.
- الصور فيها `alt` و`width/height` (لمنع layout shift) والصور تحت الهيرو `lazy`.
- الأيقونات SVG sprite داخلي — مفيش أي أيقون فونت خارجي.
- الخطوط `font-display: swap` مع `preload` للخطين الأساسيين.
- بدون JS: المحتوى ظاهر بالكامل وشاشة التحميل مخفية والواتساب شغّال.
