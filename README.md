# Malek for Website — معرض أعمال وباقات

موقع شخصي عربي (RTL) لمقدم خدمة تصميم وتطوير المتاجر الإلكترونية، مع معرض
للمشاريع الحقيقية، وباقات أسعار، وربط مباشر بالواتساب.

الملف الجاهز للنشر هو **`index.html`** — ملف واحد مستقل تمامًا: الخطوط
(El Messiri / Cairo / Cormorant) وصور المشاريع وكل الـ CSS والـ JS مضمّنين
داخله كـ data URIs، فلذلك يعمل أوفلاين وداخل أي معاينة sandbox تمنع الطلبات
الخارجية. لا CDN ولا npm ولا خطوة بناء مطلوبة للنشر.

```
index.html            ← النسخة النهائية (مستقلة، ~630 KB)
src/index.html        ← HTML الدلالي القابل للتعديل
src/styles.css        ← التصميم كامل (tokens + components + breakpoints)
src/app.js            ← شاشة التحميل، الريفييل، العدادات، رسائل الواتساب
assets/projects/*.webp ← صور المشاريع (من مشروعي عوام الدلنجات وCLOTHINA)
fonts/*.woff2         ← El Messiri + Cairo (عربي ولاتيني) + Cormorant
build.py              ← يعيد بناء index.html من ملفات src/
vercel.json           ← إعدادات نشر على Vercel (clean URLs + headers)
tailwind.config.cjs   ← نسخة اختيارية من الـ tokens إذا حبيت تنقلها لـ Tailwind
```

بعد أي تعديل في `src/`:

```bash
python3 build.py
```

## ربط الواتساب

الرقم: **+20 105 524 7802** (`201055247802`) — في مكان واحد داخل `src/app.js`:

```js
var PHONE = '201055247802';
```

كل زر فيه `data-wa="..."` بياخد رسالة جاهزة مختلفة:

| data-wa | الرسالة |
| --- | --- |
| `plan-1` / `plan-2` / `plan-3` | اسم الباقة + السعر + كل تفاصيلها سطر سطر |
| `advice` | طلب ترشيح باقة |
| `general` | رسالة عامة للتواصل |
| نموذج التواصل | الاسم + الباقة + تفاصيل المشروع |

الروابط نفسها **مكتوبة ومُرمّزة مسبقًا في HTML**، فلو الجافاسكريبت متعطّل
الزر شغّال برضه. لما حد يدوس على أي باقة، بيفتح واتساب على الرقم برسالة
جاهزة فيها الباقة اللي داس عليها وتفاصيلها.

## التصميم

| Token | القيمة | الاستخدام |
| --- | --- | --- |
| `--bg` | `#07090D` | خلفية الصفحة |
| `--panel` | `#0D1118` | الكروت |
| `--ink` | `#F3EEE2` | النصوص الأساسية |
| `--muted` | `#9A968C` | النصوص الثانوية |
| `--gold` | `#D9B36B` | الأكسنت الذهبي |
| `--gold-grad` | `#F7E7C0 → #D9B36B → #9A7433` | اللوجو والأسعار والأزرار |
| `--display` | El Messiri | العناوين العربية |
| `--sans` | Cairo | النصوص والأزرار |
| `--serif` | Cormorant | الأرقام واللاتيني (MALEK / MW / 2026) |

الشبكة مبنية بـ `clamp()` وبريك بوينتس عند **1080 / 980 / 700 / 560 / 420px**.
الموقع كامل RTL عبر `dir="rtl"` وخصائص منطقية (`inset-inline`, `padding-inline`).

### اللوجو
مونوجرام **MW** مرسوم هندسيًا (مش خط جاهز): الحرف `M` بأبيض عاجي والحرف `W`
بتدرّج ذهبي، في بلاطة مربعة دائرية الحواف. نفس المارك مستخدم في:
شاشة التحميل (بيترسم بالأنيميشن)، الهيدر، الفوتر، وfavicon.

## الحركة والأنيميشن

- **شاشة التحميل**: رسم المونوجرام stroke-by-stroke، دوران رنين، ظهور
  «MALEK / FOR WEBSITE» بحركة صاعدة، شريط تقدّم بنسبة مئوية، ثم ستارة
  شفافة تفتح بعد ~1.5 ثانية من التحميل (بحد أقصى 5.2 ثانية أمان).
- **دخول الهيرو**: كل سطر بيظهر بتأخير متتابع بعد فتح الستارة.
- **ظهور السكاشن**: IntersectionObserver + `translateY` + fade مع `data-delay`.
- **عدادات الأرقام** في الهيرو بتعد لحد الرقم النهائي.
- **خط سير الماركي**، ختم دوّار، أورب بخلفية متحركة، شريط تقدم الصفحة.
- **تأثير ميل بسيط** لكروت الباقات مع حركة المؤشر (ديسكتوب فقط).
- كل الحركة تحترم `prefers-reduced-motion`: بتتحول لنسخة ساكنة فورًا.

## النشر

Vercel جاهز (Static / Other، بدون Build Command، Output = الجذر):

```bash
npx vercel --prod
```

أو ارفع الريبو على GitHub واربطه بمشروع Vercel جديد؛ `index.html` هو الملف
اللي هيتقدّم تلقائيًا. ملف `vercel.json` بيضبط clean URLs وheaders للكاش
والأمان.

## إمكانية الوصول والأداء

- HTML صالح 100% حسب `html-validate` (semantic landmarks, labels, roles).
- skip link، حالات تركيز واضحة، `aria-expanded` / `aria-live` على الحالة.
- الصور فيها `alt` و`width/height` (لمنع layout shift) والصور تحت الهيرو `lazy`.
- الأيقونات SVG sprite داخلي — مفيش أي أيقون فونت خارجي.
- الخطوط `font-display: swap` مع `preload` للخطين الأساسيين.
- بدون JS: المحتوى ظاهر بالكامل وشاشة التحميل مخفية والواتساب شغّال.
