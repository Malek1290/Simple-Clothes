# Main character reference

`reference.png` is the user's supplied character sheet (`Untitled.png`).
The production character follows the solid white figure in the first column:
round head, no facial features, a small neck gap, tapered solid torso,
thick round-ended arms and legs. No gray backdrop, outline variants, or glow.

The production Canvas rig in `src/app.js` recreates this silhouette as articulated
geometry so it can climb the actual code lines. This is not a sprite-sheet player
or a Rive export. The same round head and substantial hand are used in the final
blackout peek. Story timing, code-box geometry and controls are unchanged.
